Token Radar ranks pre-token DefiLlama protocols by implied launch value. radar-2 calibrates each category's multiple on the market itself (the median market-cap-to-TVL of live-token protocols in that category, shrunk toward the live set's median), backtested leave-one-out against radar-1's flat 0.25x, with a 7-step farm plan per protocol derived from its category, chains, TVL and age, on a sortable, filterable dashboard.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
